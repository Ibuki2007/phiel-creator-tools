# Life Quest — 人生RPGクエストボード

毎日の活動を「クエスト」に変換し、次にやることを直感的に選べる個人用Webアプリです。VTuber活動、創作、音声、イラスト、生活管理を、XPとレベルアップで楽しく続けられます。

## 主な機能

- メイン／サブ／デイリーのクエスト分類とフィルター
- 難易度、獲得XP、優先度、締切、所要時間の管理
- ハードルを下げる「5分だけやる」最小版タスク
- クエストの追加・編集・削除・完了演出
- レベル、経験値バー、当日の達成数をリアルタイム表示
- LocalStorageへの自動保存と日付変更時のデイリー自動リセット
- JSONファイルでのバックアップ／復元
- PC／スマートフォン対応のレスポンシブなダークUI

## ローカルで起動

Node.js 20以降を用意し、以下を実行します。外部パッケージへの依存はありません。

```bash
npm install
npm run dev
```

ターミナルに表示される `http://localhost:5173` をブラウザで開いてください。

### テストと本番ビルド

```bash
npm test
npm run build
npm run preview
```

ビルド成果物は `dist/` に生成されます。本アプリは外部APIやサーバーを必要とせず、データは利用中のブラウザ内だけに保存されます。別のブラウザや端末へ移す際は、画面右上の「↓」からバックアップし、「↑」から復元してください。

## GitHub Pagesで公開

1. リポジトリをGitHubへpushします（既定の公開ブランチは `main` です）。
2. GitHubの **Settings → Pages → Build and deployment** を開きます。
3. **Source** で **GitHub Actions** を選択します。
4. `main` ブランチへのpush、またはActions画面からの手動実行で自動的にテスト・ビルド・公開されます。
5. 完了後、Pages画面またはActionsのdeployジョブに公開URLが表示されます。

別名の公開ブランチを使う場合は `.github/workflows/deploy.yml` の `branches: [main]` を変更してください。相対アセットパスを使用しているため、プロジェクトサイト（`https://ユーザー名.github.io/リポジトリ名/`）でも動作します。

## データについて

データはキー `life-quest-board-v1` でLocalStorageへ保存されます。ブラウザのサイトデータを削除すると消えるため、定期的なJSONバックアップをおすすめします。復元時は、本アプリから書き出したJSONファイルを選択してください。
